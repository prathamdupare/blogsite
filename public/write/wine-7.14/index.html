The Wine development release 7.14 is now available.
August 1, 2022

Wine continues to provide and improve Windows compatibility on Linux as Wine 7.14 is released. Wine is the compatibility layer that allows you to run various Windows applications and games on Linux (and forms part of Steam Play Proton).

Wine 7,14 release:

  • More progress on syscall interface for USER32.
  • Improved font fallbacks in DirectWrite.
  • Some fixes for socket shutdowns.
  • Various bug fixes.

Various problems and bug fixes solved with: Civilization IV, Unravel Two, Waves Central, Cheat Engine, World of Tanks, Roblox, Total War Shogun 2.
